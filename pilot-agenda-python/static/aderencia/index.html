Ranking de linhas

Score de risco = 50% volume + 30% taxa de divergência + 20% severidade (participação de registros com divergência ≥ 70%). Cada componente é normalizado de 0 a 1 dentro do recorte. Linhas com taxa de divergência acima de μ + 2σ aparecem em vermelho.

Tabelas de horário (Identificação)

Uma tabela pode operar linhas diferentes ao longo do período. Os totais somam todas as linhas em que a tabela apareceu.

Adicionar dados à base

Cole ou carregue um arquivo CSV com os novos meses. Os registros entram na base pra todo mundo que usa o painel assim que você aplicar. Registros com a mesma chave (tabela + linha + tipo de dia + mês + ano) substituem os existentes.

Ou cole o conteúdo diretamente (copiar do Excel também funciona — usa TAB como separador):

Formato aceito

ColunaObrigatóriaAceita
IdentificaçãoSimCódigo da tabela de horário, ex. HA004. Também aceita os nomes ID, Tabela ou Prefixo.
LinhaSimCódigo da linha, ex. 680, X41. Linhas novas são criadas automaticamente.
Total ProgxReal · Diferente · IgualDois dos trêsInteiros. O terceiro é calculado. Se os três vierem e não fecharem (Igual + Diferente ≠ Total), o registro é rejeitado.
DiaSimÚtil, Sábado, Domingo — com ou sem acento.
MêsSimNúmero 1–12, nome (Maio), 05/2026 ou 2026-05-01.
AnoSim*Ex. 2026. Dispensável se o mês vier como data completa.
Grupo de OperaçãoSó para linha novaSe a linha já existe na base, o grupo cadastrado é usado quando a coluna vier vazia.

A validação nunca aplica nada sozinha: ela mostra quantos registros são novos, quantos substituem existentes e quais foram rejeitados e por quê. Só depois o botão Aplicar à base é liberado.
