🧩 Gerenciar Sistemas (cards do menu)

Adicione sistemas ao menu sem editar código nem mexer no servidor: clique em 📤 Enviar HTML e escolha o arquivo, preencha nome, emoji e descrição, e clique em Salvar card. O card aparece para todos na hora. Arquivos grandes vão em partes, então o limite do servidor não atrapalha.

🎨 Personalizar sistemas padrão

Edite nome, emoji, descrição e cor de qualquer card do menu. Vale para todos os usuários.

📁 Pastas de organização

Crie pastas (ex.: Treinamento, Frota) e coloque sistemas dentro delas — no menu, a pasta vira um card: clique para ver o que está dentro. Para colocar um sistema numa pasta, edite o card (✏️) e escolha a pasta.

📊 Fontes de Dados (planilhas na nuvem)

Ligue cada sistema a uma planilha do Google: atualizou a planilha, o sistema lê os dados novos sozinho — sem gerar HTML novo.
Como publicar: no Google Planilhas → Arquivo → Compartilhar → Publicar na web → escolha a aba e o formato CSV → copie o link e cole abaixo.

💡 Nos sistemas (HTML), leia os dados com: const dados = await parent.hubPlanilha('combustivel') — retorna as linhas da planilha como lista de objetos (1ª linha = nomes das colunas). Cache de 5 min no servidor; a URL da planilha fica protegida no banco.

💾 Sincronizacao de Dados

Os dados dos tres sistemas sao sincronizados automaticamente com o banco MySQL a cada 60 segundos e ao fechar um sistema. Isso garante que qualquer computador veja os mesmos dados.

🔒 Seguranca

Senhas com bcrypt, autenticacao em 2 etapas (Google Authenticator) e bloqueio automatico apos varias tentativas erradas. Nenhuma senha fica no codigo-fonte.

🔗 Convidar novo usuário (link)

Gere um link e envie para a pessoa. Ao abrir, ela cria o próprio login, senha e já cadastra o Google Authenticator sozinha. O link vale por 7 dias e só pode ser usado uma vez.

📱 Convites via WhatsApp (n8n)

Cole a URL do webhook do seu n8n. Ao criar uma reserva de sala, o portal envia os dados do convite para o n8n disparar no WhatsApp.

📇 Contatos do WhatsApp

Cadastre o nome e o número de cada pessoa. Quando uma reserva de sala for criada, o portal envia ao n8n o número do responsável e de quem criou — prontos para o disparo no WhatsApp. Formato: 55 + DDD + número (ex.: 5541999998888).

📢 Comunicado via WhatsApp

Escreva uma mensagem e envie pelo n8n para os contatos cadastrados (todos ou um específico).
